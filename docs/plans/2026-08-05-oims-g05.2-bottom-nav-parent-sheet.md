## Context

Bottom nav sekarang: slot Inventory/Laporan/Sistem itu **parent** dengan banyak child, tapi klik parent langsung loncat ke 1 child sewenang-wenang (`/inventory/stok`, `/laporan/stok`). Terasa janggal — kenapa Stok yang dipilih? User juga tak sadar ada child lain tanpa buka Menu.

**Keputusan:** slot parent buka **bottom-sheet berisi child section itu** (user pilih), bukan loncat. Slot leaf (Dashboard) tetap navigate langsung. Slot Menu ke-5 = sheet **accordion** collapse per parent (seperti sidebar desktop) — scalable saat Tahap 2-5 nambah section (~9 total). Ini reuse pola accordion sidebar existing, bukan bikin baru.

## Task 1 — menu-sheet.tsx: accordion + scoped mode

File: `src/components/layouts/bottom-nav/menu-sheet.tsx`

Tambah prop opsional `section?` supaya sheet bisa 2 mode:
- **Full mode** (slot Menu, `section` undefined) → render accordion: tiap `NavItem` yang punya `items[]` jadi header collapse. Tap header → expand child. Reuse pola `expandedItems` dari sidebar (satu terbuka).
- **Scoped mode** (slot parent, `section` = 1 NavSection) → render langsung sub-item section itu (flat, tanpa accordion — karena cuma 1 parent, langsung tampil child-nya).

```tsx
type MenuSheetProps = {
  open: boolean;
  onClose: () => void;
  userRole: string;
  section?: NavSection;  // kalau ada = scoped mode (1 section), kalau tidak = full accordion
};
```

Implementasi:
- Import `NAV_DATA` + type `NavSection` dari `sidebar/data`.
- Full mode: `const sections = NAV_DATA.filter(s => !s.ownerOnly || userRole === "owner")`. Untuk tiap section → tiap `item`:
  - Kalau `item.items.length > 0` → render accordion header (title + icon + chevron), expand state via `useState<string[]>` `expandedItems` + `toggleExpanded(title)` (pola sidebar: `prev.includes(title) ? [] : [title]`). Child render kalau `expandedItems.includes(item.title)`.
  - Kalau `item.url` (leaf, mis. Dashboard) → render tombol navigate langsung.
- Scoped mode: kalau `section` prop ada → render sub-item dari `section.items[].items` (flatten 1 level) langsung sebagai list tombol, tanpa accordion. Judul sheet = `section.label` atau nama parent.
- Sub-item tap → `router.push(url)` + `onClose()` + loading (useTransition, pola existing).
- Pertahankan: backdrop, slide-up, `max-h-[85vh] overflow-y-auto`, `rounded-t-2xl`, dark tokens, `min-[850px]:hidden`, close on route change, scroll trap.
- Chevron icon: reuse pola sidebar (`ChevronUp` rotate) atau SVG inline sederhana.

## Task 2 — bottom-nav/index.tsx: slot parent buka sheet scoped

File: `src/components/layouts/bottom-nav/index.tsx`

- `NAV_SLOTS`: tambah field bedakan leaf vs parent. Tiap slot parent link ke `NavSection` yang sesuai (via `label` atau index NAV_DATA).
  ```ts
  type NavSlot = {
    label: string;
    baseRoute: string;
    icon: (...) => React.ReactElement;
    type: "leaf" | "parent";
    url?: string;              // leaf: navigate ke sini
    sectionLabel?: string;     // parent: buka sheet section ini (match NAV_DATA label)
  };
  ```
  - Dashboard: `type: "leaf", url: "/dashboard"`.
  - Inventory: `type: "parent", sectionLabel: "MANAJEMEN"` (section berisi Master + Inventory) — ATAU lebih presisi: buat scoped sheet berisi item "Inventory" saja. **Putuskan saat coding:** kalau mau slot Inventory hanya tampilkan sub-inventory (bukan master), scoped ke `NavItem` "Inventory", bukan section. Rekomendasi: scoped ke item level (Inventory item → 5 sub-menu inventory), lebih fokus.
  - Laporan: parent → item "Laporan" (5 laporan).
  - Sistem: parent → item "Sistem" (owner-only, sudah ke-filter).
- State: `const [activeSheet, setActiveSheet] = useState<NavSection | NavItem | null>(null)` + `menuOpen` untuk slot Menu penuh.
- Klik handler:
  - Leaf → `navigate(slot.url)`.
  - Parent → `setActiveSheet(<item/section terkait>)` (buka sheet scoped).
  - Menu → `setMenuOpen(true)` (sheet full accordion).
- Render `<MenuSheet>` 2x atau 1x dengan prop kondisional: kalau `activeSheet` → scoped, kalau `menuOpen` → full. Lebih simpel: 1 MenuSheet, prop `section={activeSheet ?? undefined}` + `open={menuOpen || !!activeSheet}`.
- Active state slot tetap `pathname.startsWith(baseRoute)` — parent aktif kalau di child mana pun.
