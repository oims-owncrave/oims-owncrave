## Context

`MobileHomeHeader` (greeting gradient di /dashboard mobile) belum ada **wave shape** — di-skip saat g05.3 ("biar ringkas"). Owner mau tampilan seperti SM/Better Finance: lengkung gelombang di bawah header gradient (transisi mulus ke konten). Tambah SVG wave.

## Fakta terverifikasi

- `src/components/layouts/header/mobile-home-header.tsx` — `<div className="min-[850px]:hidden bg-linear-to-r from-primary to-indigo-700 px-5 py-8 text-white shadow-md">` berisi avatar + nama + role + Settings button.
- Pola SM: `app/(admin)/home/page.tsx` — wave = `<div className="absolute bottom-0 left-0 w-full h-8"><svg viewBox="0 0 400 32" preserveAspectRatio="none"><path d="M0,32 Q100,20 200,32 T400,20 L400,32 Z" fill="rgb(249 250 251)"/></svg></div>`.
- Warna konten belakang header = `bg-gray-2` (main-content) light / `dark:bg-[#020d1a]` dark. Wave fill harus match ini biar nyatu.

## Task 1 — Tambah wave SVG

File: `mobile-home-header.tsx`
- Bungkus root div jadi `relative overflow-hidden` (biar wave absolute tak bocor).
- Sesuaikan padding bawah (`pb-*` lebih besar, mis `pb-12`) supaya konten tak ketiban wave.
- Tambah wave di bawah (sebelum `</div>` root):
  ```tsx
  <div className="absolute bottom-0 left-0 h-6 w-full">
    <svg viewBox="0 0 400 32" className="h-full w-full" preserveAspectRatio="none">
      <path d="M0,32 Q100,20 200,32 T400,20 L400,32 Z" className="fill-gray-2 dark:fill-[#020d1a]" />
    </svg>
  </div>
  ```
- **Fill match konten:** pakai `fill-gray-2 dark:fill-[#020d1a]` (Tailwind fill utility) — HARUS sama dengan bg main-content. Verifikasi warna di `main-content.tsx` (`bg-gray-2 dark:bg-[#020d1a]`).
- Konten header (avatar row) bungkus `relative z-10` supaya di atas wave.
