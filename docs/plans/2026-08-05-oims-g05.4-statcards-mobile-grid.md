## Context

Dashboard punya 8 StatCards KPI. Grid sekarang `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4` → di HP (< 640px) semua 8 card **stack 1 kolom vertikal**, user harus scroll panjang sebelum sampai panel PerluPerhatian. Fix ringan: 2 kolom dari ukuran HP terkecil supaya 8 card = 4 baris, tak scroll jauh.

## Task 1 — grid 2 kolom dari mobile

File: `src/app/(with-layout)/dashboard/_components/StatCards.tsx` (baris ~82, wrapper grid)

Ganti:
```tsx
<div className="grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-4">
```
jadi:
```tsx
<div className="grid grid-cols-2 gap-3 lg:grid-cols-4">
```
- `grid-cols-2` dari mobile terkecil (8 card → 2 kolom → 4 baris).
- `gap-3` (bukan `gap-4`) supaya card tak terlalu sempit di layar 360px.
- `lg:grid-cols-4` tetap (desktop 4 kolom).

## Task 2 — value text tak overflow di card sempit

Card value pakai `text-xl` (baris ~103). Di card sempit (~165px di HP 360px), value rupiah panjang (mis. "Rp 12.500.000") bisa overflow.

Ganti value `<p>`:
```tsx
<p className="mt-1 text-xl font-bold text-dark dark:text-white">
```
jadi:
```tsx
<p className="mt-1 text-lg font-bold text-dark dark:text-white lg:text-xl">
```
- `text-lg` di mobile (lebih aman), `lg:text-xl` kembali besar di desktop.

## Verifikasi

1. **Mobile (360-640px):** dashboard → 8 card tampil 2 kolom, 4 baris. Value rupiah tak terpotong/overflow keluar card.
2. **Tablet (640-1024px):** tetap 2 kolom (atau naik sesuai `lg`).
3. **Desktop (≥1024px):** 4 kolom, value `text-xl` seperti sebelumnya.
4. `pnpm run type-check` clean.
