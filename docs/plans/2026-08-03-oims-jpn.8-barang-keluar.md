## Context

Barang keluar = pengeluaran bahan ke produksi/cutting (PRD §11). Efek:
1. Insert `barang_keluar` (header) + `barang_keluar_detail`.
2. Tiap detail → append `mutasi_stok` (tipe `keluar`, kuantitas **NEGATIF**).
3. **Snapshot harga**: `barang_keluar_detail.hargaSatuan` = `bahan.hargaRataRata` SAAT keluar (bukan input user). Subtotal = qty × harga rata² saat itu.
4. Kurangi `stok.kuantitas`.

Nomor dokumen `BK-YYYYMM-NNNN`. Schema `barangKeluar`, `barangKeluarDetail` sudah ada.

---

## Beda kritis dari barang masuk

| Aspek | Barang Masuk | Barang Keluar |
|---|---|---|
| Harga satuan | Input user | **Snapshot `bahan.hargaRataRata`** (tidak input, ambil saat transaksi) |
| hargaRataRata bahan | Di-update (weighted avg) | **TIDAK diubah** (keluar tak ubah harga rata²) |
| Mutasi kuantitas | Positif | **Negatif** |
| Tipe mutasi | `masuk` | `keluar` |
| Guard | — | **Stok cukup** — qty keluar ≤ stok tersedia, else reject |
| Header field | supplier, invoice | `tujuan` (mis. "Cutting PO-001") |
| createdBy role | owner, admin_gudang | owner, admin_gudang |

## Task 2 — Server Action (`src/services/barang-keluar.ts`)

Pola identik barang masuk, dengan beda:
```typescript
export async function createBarangKeluar(input: BarangKeluarInput) {
  const user = await requireRole(["owner", "admin_gudang"]);

  return db.transaction(async (tx) => {
    // GUARD stok cukup — cek SEBELUM insert apapun
    for (const d of input.detail) {
      const [s] = await tx.select().from(stok).where(eq(stok.bahanId, d.bahanId)).limit(1);
      const tersedia = Number(s?.kuantitas ?? 0);
      if (d.kuantitas > tersedia) {
        const [b] = await tx.select({ nama: bahan.nama }).from(bahan).where(eq(bahan.id, d.bahanId)).limit(1);
        // rollback via throw
        throw new Error(`Stok ${b?.nama ?? "bahan"} tidak cukup (tersedia ${tersedia})`);
      }
    }

    const nomorDokumen = await generateDocNumber("BK", "barang_keluar");
    const [header] = await tx.insert(barangKeluar).values({
      nomorDokumen, tujuan: input.tujuan || null,
      tanggal: new Date(input.tanggal), catatan: input.catatan || null,
      createdBy: user.id,
    }).returning();

    for (const d of input.detail) {
      // snapshot harga rata2 saat ini
      const [b] = await tx.select().from(bahan).where(eq(bahan.id, d.bahanId)).limit(1);
      const hargaSnapshot = Number(b.hargaRataRata);
      const subtotal = d.kuantitas * hargaSnapshot;

      await tx.insert(barangKeluarDetail).values({
        barangKeluarId: header.id, bahanId: d.bahanId,
        kuantitas: String(d.kuantitas), hargaSatuan: String(hargaSnapshot),
        subtotal: String(subtotal),
      });

      // append mutasi — kuantitas NEGATIF
      await tx.insert(mutasiStok).values({
        bahanId: d.bahanId, tipe: "keluar", kuantitas: String(-d.kuantitas),
        barangKeluarId: header.id, createdBy: user.id,
      });

      // kurangi stok cache
      const [s] = await tx.select().from(stok).where(eq(stok.bahanId, d.bahanId)).limit(1);
      const stokBaru = Number(s.kuantitas) - d.kuantitas;
      await tx.update(stok).set({ kuantitas: String(stokBaru), updatedAt: new Date() })
        .where(eq(stok.bahanId, d.bahanId));
      // hargaRataRata TIDAK diubah
    }

    await tx.insert(auditLog).values({
      userId: user.id, aksi: "CREATE", tabel: "barang_keluar", recordId: header.id,
      dataBefore: null, dataAfter: JSON.stringify({ header, detail: input.detail }),
    });
    return { data: header };
  });
}
```
> Throw di dalam transaction → rollback otomatis. Client tangkap error message. (Bungkus try/catch di action kalau mau return `{error}` alih-alih throw — lebih ramah untuk toast. Pilih satu, konsisten.)
