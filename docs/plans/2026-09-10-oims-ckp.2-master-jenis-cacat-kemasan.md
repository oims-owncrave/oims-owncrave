# oims-ckp.2 — Master Jenis Cacat + Master Kemasan

> Tahap 4 · Gelombang 4A (fondasi) · Prio P1 · Executor: **Antigravity**
> Epic: `oims-ckp` · Blocks: `.1` standar QC, `.7` temuan cacat, `.12` packing

## Konteks

Dua master kecil, keduanya CRUD murni tanpa keputusan desain. Digabung satu issue supaya
tidak dua kali cold-start untuk kerja yang identik.

- **Jenis cacat** dipakai `.7` (temuan cacat) dan `.1` (detail standar QC).
- **Kemasan** dipakai `.12` (packing).

App lama TIDAK punya keduanya (`docs/referensi-oims-production.md` §10: standar QC & jenis
cacat "❌ tidak ada", finishing/packing "❌ tidak ada") — ini greenfield, tapi bentuknya
master CRUD biasa jadi risikonya rendah.

## Pola wajib

**BACA `docs/plans/_pola-master-crud.md` DULU dan ikuti persis.** File itu single source of
truth untuk struktur file, DataTable kit, modal, toast, partial unique index. Plan ini hanya
menyebut yang **spesifik** ke dua master ini.

Acuan hidup yang boleh dicontek struktur JSX-nya: `src/app/(with-layout)/master/kategori/`.

## Task 2 — Tabel `jenis_cacat` ⚡ CLAUDE VIA MCP

```ts
export const jenisCacat = pgTable(
  "jenis_cacat",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    kode: text("kode").notNull(),                    // BUKAN .unique() — lihat index bawah
    nama: text("nama").notNull(),
    kategori: cacatKategoriEnum("kategori").notNull(),
    keparahan: qcTingkatEnum("keparahan").notNull(),
    sumber: cacatSumberEnum("sumber").notNull().default("tidak_diketahui"),
    dapatDiperbaiki: boolean("dapat_diperbaiki").notNull().default(true),
    tindakanDefault: text("tindakan_default"),
    isActive: boolean("is_active").notNull().default(true),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp("updated_at", { withTimezone: true }).notNull().defaultNow(),
    deletedAt: timestamp("deleted_at", { withTimezone: true }),
  },
  (t) => [
    uniqueIndex("jenis_cacat_kode_active_unique").on(t.kode).where(isNull(t.deletedAt)),
    index("jenis_cacat_kategori_idx").on(t.kategori),
  ]
);
```

## Task 3 — Tabel `kemasan` ⚡ CLAUDE VIA MCP

```ts
export const kemasan = pgTable(
  "kemasan",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    kode: text("kode").notNull(),
    nama: text("nama").notNull(),
    jenis: kemasanJenisEnum("jenis").notNull(),
    ukuran: text("ukuran"),
    bahanKemasan: text("bahan_kemasan"),             // deskriptif, BUKAN FK ke tabel bahan
    supplierId: uuid("supplier_id").references(() => supplier.id),
    biaya: numeric("biaya", { precision: 15, scale: 2 }).notNull().default("0"),
    stokMinimum: numeric("stok_minimum", { precision: 15, scale: 2 }).notNull().default("0"),
    isActive: boolean("is_active").notNull().default(true),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp("updated_at", { withTimezone: true }).notNull().defaultNow(),
    deletedAt: timestamp("deleted_at", { withTimezone: true }),
  },
  (t) => [
    uniqueIndex("kemasan_kode_active_unique").on(t.kode).where(isNull(t.deletedAt)),
    index("kemasan_supplier_idx").on(t.supplierId),
  ]
);
```

Catatan kolom:
- `supplierId` **reuse tabel `supplier` Tahap 1** — jangan bikin master supplier kemasan baru.
- `biaya` & `stokMinimum` `numeric` (aturan proyek: uang & kuantitas tak pernah `integer`).
- `bahanKemasan` sengaja teks bebas (mis. "PE 0.05mm"), bukan FK — kemasan bukan bahan produksi.

## Task 5 — Server Actions

`src/services/jenis-cacat.ts` dan `src/services/kemasan.ts`.
Fungsi: `listJenisCacat`, `createJenisCacat`, `updateJenisCacat`, `softDeleteJenisCacat`
(idem untuk kemasan).

Wajib tiap fungsi:
- Query hanya di Server Action (`db` dari `src/db/index.ts`).
- Semua `select` filter `isNull(deletedAt)`.
- Guard kode duplikat **aktif** sebelum insert (pesan bagus), walau DB sudah partial unique.
- `writeAudit` tiap CREATE/UPDATE/DELETE.
- Guard delete kalau sudah direferensi: jenis cacat dipakai `temuan_cacat`/`standar_qc_detail`,
  kemasan dipakai `packing_detail` → tolak, sarankan nonaktifkan. **Tabel-tabel itu belum ada
  saat issue ini dikerjakan** — tulis guard-nya sekarang dalam bentuk yang gampang diisi, atau
  beri komentar `// TODO(oims-ckp.7/.12): tambah guard referensi` supaya tak terlupa.
