## Context

Saat buka app di mobile (< 850px) dari cold load, sidebar **muncul terbuka lalu langsung menutup** — flash janggal. Root cause terverifikasi di `sidebar-context.tsx`: `useState(defaultOpen=true)` + `useIsMobile()` mulai `false`, keduanya baru sync ke kondisi mobile via `useEffect` SETELAH mount. Jadi frame pertama = sidebar terbuka + belum tahu ini mobile → render drawer terbuka, baru frame berikut menutup.

Karena mobile sekarang pakai bottom nav (`oims-2xn`, sudah live), sidebar drawer mobile **redundan** — hamburger pembukanya sudah di-`hidden`. Fix = buang jalur drawer mobile sepenuhnya, sidebar jadi desktop-only. Ini menghapus root cause flash (tak ada lagi 2 state telat sinkron di mobile).

## Task 1 — sidebar-context.tsx: buang drawer mobile state

File: `src/components/layouts/sidebar/sidebar-context.tsx`

Sekarang context expose `isMobile` + set `isOpen=false` saat mobile via useEffect (ini sumber flash). Sidebar desktop-only tak butuh `isMobile` lagi.

- Hapus `import { useIsMobile }` + `const isMobile = useIsMobile()`.
- Hapus cabang `if (isMobile) setIsOpenState(false)` di useEffect restore. Sisakan hanya restore localStorage desktop:
  ```tsx
  useEffect(() => {
    const stored = localStorage.getItem(STORAGE_KEY);
    setIsOpenState(stored === null ? defaultOpen : stored === "true");
  }, [defaultOpen]);
  ```
- Hapus `isMobile` dari context value + type `SidebarContextType`.
- `setIsOpen`: buang guard `if (!isMobile)` — selalu simpan localStorage (desktop-only sekarang).

**Catatan:** cek pemakai `isMobile`/`toggleSidebar` dari context di `sidebar/index.tsx` (Task 2) — sesuaikan.

## Task 2 — sidebar/index.tsx: desktop-only

File: `src/components/layouts/sidebar/index.tsx`

- Hapus `isMobile` dari `useSidebarContext()` destructure.
- Hapus blok **Mobile Overlay** (`{isMobile && isOpen && (<div className="fixed inset-0 z-50 ...")`).
- `<aside>` className: buang ternary `isMobile ? cn("fixed inset-y-0 ...") : cn("sticky z-30 ...")`. Sisakan **hanya** cabang desktop: `sticky z-30 shrink-0`, width `isOpen ? "w-72.5" : "w-[100.5px]"`.
- `collapsed = !isOpen && !isMobile` → jadi `collapsed = !isOpen` (tak ada isMobile).
- Cek tombol close mobile (`isMobile && isOpen ? <ArrowLeftIcon> : <MenuIcon>`): sisakan hanya branch desktop (MenuIcon toggle). Buang branch ArrowLeft mobile + `ArrowLeftIcon` import kalau tak dipakai lagi.
- `Link onClick={() => isMobile && toggleSidebar()}` → hapus `isMobile &&` (jadi tak ada onClick, atau hapus onClick).
- **Bungkus sidebar mobile-hidden:** tambah `hidden min-[850px]:block` di `<aside>` (atau di wrapper) supaya sidebar tak render sama sekali di mobile. Verifikasi tak ada layar putih/gap di mobile.
