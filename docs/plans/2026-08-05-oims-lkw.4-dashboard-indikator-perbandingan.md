# Plan — oims-lkw.4: Dashboard indikator perbandingan periode

**Tanggal:** 2026-08-05 · **Issue:** oims-lkw.4 (feature, P3) · **Parent:** oims-lkw
**Depends:** lkw.1 (sudah done) · Revisi/lanjutan lkw.1

## Context

lkw.1 bikin `AktivitasTransaksi` dengan filter periode interaktif (hari/minggu/bulan/custom), TAPI **tak ada indikator perbandingan naik/turun vs periode sebelumnya** — padahal klien minta eksplisit "perbandingan bulan ini vs bulan lalu". Tambahkan delta % + panah naik(hijau)/turun(merah) ke komponen aktivitas.

## Fakta terverifikasi

- `src/services/dashboard.ts` — `getAktivitasTransaksi(from, to)` return `{ masuk_count, masuk_nilai, keluar_count, keluar_nilai }` via query subquery 1 round-trip (`::date` range).
- `AktivitasTransaksi.tsx` — `timeFrame` state (hari/minggu/bulan/custom) + `rangeOf()` hitung from/to. `useAktivitasTransaksi` hook (placeholderData).
- Sudah pakai `ArrowDownLeft`/`ArrowUpRight` (lucide) untuk icon masuk/keluar.

## Task 1 — Service: hitung periode pembanding

File: `src/services/dashboard.ts` — `getAktivitasTransaksi`:
- Tambah return field pembanding: `masuk_count_prev`, `keluar_count_prev` (+ nilai prev opsional) — total periode **setara sebelumnya**.
- Periode pembanding = range dengan durasi sama, digeser ke belakang. Mis. `from`/`to` = bulan ini → prev = bulan lalu (durasi sama). Hitung: `prevFrom = from - (to - from + 1 hari)`, `prevTo = from - 1 hari`. Lakukan di SQL (interval) atau kirim prevFrom/prevTo dari client.
- **Simplest:** service terima `from, to` + hitung `prevFrom/prevTo` di SQL: `to - (to - from) - interval '1 day'`. Tambah subquery count untuk range prev.
- Return `{ ...current, masukCountPrev, keluarCountPrev }`.

## Task 2 — Komponen: indikator delta

File: `AktivitasTransaksi.tsx`
- Hitung delta: `deltaMasuk = masukCount - masukCountPrev`, `persen = prev > 0 ? (delta/prev*100) : (curr > 0 ? 100 : 0)`.
- Tampilkan di tiap kartu (Masuk/Keluar): badge kecil dengan panah + persen.
  - Naik: `text-green-600` + panah atas (`↑` / TrendingUp). Turun: `text-red-600` + panah bawah. Sama: netral.
  - Label: mis. "+12% vs periode lalu" atau "↑ 12%".
- Guard: prev=0 → tampil "baru" / tak NaN.
- Dark mode token.

## Verifikasi

1. Dashboard aktivitas → tiap kartu (Masuk/Keluar) ada indikator naik/turun + persen vs periode sebelumnya.
2. Ganti periode (bulan→minggu) → pembanding ikut sesuai (minggu ini vs minggu lalu).
3. Periode lalu 0 transaksi → tak NaN/Infinity.
4. Query tetap 1 round-trip (subquery prev ikut dalam query yang sama).
5. `pnpm run type-check` + `build` clean.
