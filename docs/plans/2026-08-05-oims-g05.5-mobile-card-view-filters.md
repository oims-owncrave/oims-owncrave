## Context

Dua masalah tabel di mobile:
- **C2 — tabel scroll horizontal:** semua tabel pakai `<DataTable>`. Di HP harus swipe kanan-kiri, header hilang, badge kepotong.
- **C3 — filter acak-acakan:** `TableToolbar` = `flex flex-wrap justify-between` → kontrol filter (search + ComboSelect + DateInput) wrap tak rata, 1 kiri 1 kanan gap besar. Paling parah MutasiTable (5 kontrol), StokTable (3).

**Solusi terpusat di DataTable** (1 file, semua ~12 tabel dapat gratis):
- C2: di layar `< 640px`, DataTable render row sebagai **kartu** (bukan tabel). Heuristik auto tentukan judul/highlight/detail; override via prop `mobileRole` opt-in di ColumnDef. 0 perubahan per-tabel wajib.
- C3: TableToolbar stack full-width di mobile (tiru grid SM `laporan/components/FilterSection.tsx`).

## Fakta terverifikasi

- `table.tsx` `DataTable` — punya `visibleColumns` (label + renderCell), `processedData`, `getRowId`, expansion, selection, loading skeleton, empty state. Card reuse semua ini.
- `renderCell(item, meta)` sudah render badge/warna/format Rp → otomatis kepakai di card value.
- `TableToolbar` @ `table-toolbar.tsx` — `flex flex-wrap items-center justify-between gap-4 p-4 sm:p-6`. Ini yang bikin filter acak di mobile.
- `TableSearch` @ `table-search.tsx` — input `w-full sm:w-64`, wrapper `<div className="relative">` (belum `w-full` di mobile).
- `useIsMobile()` @ `hooks/use-mobile.ts` — breakpoint 850. Untuk card, breakpoint 640 lebih pas (tablet portrait masih muat tabel). **Putuskan saat coding:** bikin varian 640 atau pakai CSS `sm:` visibility (render dua-duanya, sembunyikan salah satu via class — lebih SSR-safe, no flash). Rekomendasi: **CSS visibility** — `<table>` di `hidden sm:table`, card list di `sm:hidden`. Hindari `useIsMobile` untuk hindari flash + SSR mismatch.
- MutasiTable pakai server-pagination custom DI LUAR DataTable (di bawahnya) — card cuma gantikan `<table>`, kontrol pagination luar tak tersentuh.

## Task 1 — ColumnDef.mobileRole (use-table.ts)

Tambah 1 field opsional di interface `ColumnDef`:
```ts
mobileRole?: "title" | "highlight" | "detail" | "action" | "hide";
```
Komentar: "Override hierarki card mobile. Default = heuristik auto di DataTable."

## Task 2 — Card render di DataTable (table.tsx)

Tambah blok card, di-toggle CSS (`sm:hidden` untuk card, `hidden sm:table` untuk wrapper tabel existing).

**Heuristik role (kalau `mobileRole` tak diset):**
```ts
function inferRole(col, index): "title" | "highlight" | "detail" | "action" {
  if (col.mobileRole) return col.mobileRole;              // override menang
  const isAction = col.sortable === false && col.align === "center"
                   && (col.key === "id" || /aksi|action/i.test(String(col.label)));
  if (isAction) return "action";
  if (index === 0) return "title";                        // kolom pertama = judul
  if (col.align === "right") return "highlight";          // angka/nilai kanan = highlight
  return "detail";
}
```
- Kolom `mobileRole: "hide"` → skip di card.

**Struktur kartu per row:**
```tsx
<div className="sm:hidden space-y-3 p-4">
  {processedData.map((item, i) => {
    const rowId = getRowId(item, i);
    const roles = visibleColumns.map((c, idx) => ({ col: c, role: inferRole(c, idx) }));
    const title = roles.find(r => r.role === "title");
    const highlights = roles.filter(r => r.role === "highlight");
    const details = roles.filter(r => r.role === "detail");
    const actions = roles.filter(r => r.role === "action");
    return (
      <div key={rowId} className="rounded-xl border border-stroke bg-white p-4 shadow-1 dark:border-dark-3 dark:bg-gray-dark">
        <div className="flex items-start justify-between gap-2">
          <div className="min-w-0 font-semibold text-dark dark:text-white">
            {title && renderVal(title.col, item, i)}
          </div>
          <div className="flex shrink-0 items-center gap-2">
            {highlights.map(h => <div key={h.col.key}>{renderVal(h.col, item, i)}</div>)}
          </div>
        </div>
        <dl className="mt-3 space-y-1.5">
          {details.map(d => (
            <div key={d.col.key} className="flex justify-between gap-2 text-sm">
              <dt className="text-dark-5 dark:text-dark-6">{d.col.label}</dt>
              <dd className="text-right text-dark dark:text-white">{renderVal(d.col, item, i)}</dd>
            </div>
          ))}
        </dl>
        {actions.length > 0 && (
          <div className="mt-3 flex justify-end gap-2 border-t border-stroke pt-3 dark:border-dark-3">
            {actions.map(a => <div key={a.col.key}>{renderVal(a.col, item, i)}</div>)}
          </div>
        )}
      </div>
    );
  })}
</div>
```
- `renderVal(col, item, i)` = `col.renderCell ? col.renderCell(item, {rowIndex:i, isExpanded, isSelected}) : String(item[col.key] ?? "")` (reuse logic cell existing).
- **Loading:** kalau `table.isLoading` → render 3-4 card skeleton (`animate-pulse` blok). **Empty:** `processedData.length === 0` → 1 card "Tidak ada data".
- **Selection/expansion:** kalau `enableSelection` → tambah checkbox di card header. Kalau `renderExpandedRow` → card tap toggle expand, render di bawah card. (Opsional — kalau tabel yang pakai expansion sedikit, bisa defer; verifikasi tabel mana pakai.)
- Bungkus tabel `<table>` existing di `hidden sm:block` (container `overflow-auto` existing → `hidden sm:table` atau wrapper `hidden sm:block`).

## Task 3 — TableToolbar stack full-width mobile

File: `table-toolbar.tsx`. Ganti:
```tsx
<div className={cn("flex flex-wrap items-center justify-between gap-4 p-4 sm:p-6", className)}>
```
jadi:
```tsx
<div className={cn("flex flex-col gap-3 p-4 sm:flex-row sm:flex-wrap sm:items-center sm:justify-between sm:gap-4 sm:p-6", className)}>
```
- Mobile: stack vertikal. `≥sm`: perilaku lama.

File: `table-search.tsx`. Wrapper `<div className="relative">` → `<div className={cn("relative w-full sm:w-auto", className)}>` (input sudah `w-full sm:w-64`).

**Per-tabel filter group:** tabel yang bungkus filter dalam `<div className="flex items-center gap-3">` (StokTable, MutasiTable) → ganti `flex flex-col gap-2 sm:flex-row sm:items-center sm:gap-3`, tiap ComboSelect/DateInput wrapper `w-full sm:w-auto`. Cek ComboSelect/DateInput support `className`/full-width — kalau belum, bungkus `<div className="w-full sm:w-auto">`.
- Tabel yang punya filter: StokTable, MutasiTable, LaporanStok/Masuk/Keluar/Mutasi/NilaiPersediaan, BarangMasuk/KeluarTable (search saja OK).
