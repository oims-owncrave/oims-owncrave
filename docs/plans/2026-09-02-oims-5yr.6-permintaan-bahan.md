# Plan: Permintaan Bahan + Integrasi Barang Keluar (oims-5yr.6)

> PRD Tahap 2 §10 + ruang lingkup §2.7. Issue `oims-5yr.6`, depends 5yr.5. **Dieksekusi langsung Claude.**

## Keputusan desain

- Nomor `PB-YYYYMM-NNNN` via `generateDocNumber` (extend union "PB"/"permintaan_bahan").
- Status enum `pb_status`: `draft → diajukan → disetujui | ditolak`. **`jumlah_dikeluarkan` TIDAK disimpan** — derived dari `barang_keluar_detail` via FK baru `barang_keluar.permintaan_bahan_id` (pola status-derived referensi §4). Label "selesai" derived saat semua bahan dikeluarkan ≥ disetujui.
- Approve wholesale: `jumlah_disetujui = jumlah_diminta` semua baris (ponytail: per-row edit approval nanti kalau owner minta).
- Buat PB dari halaman PO (prefill baris dari estimasi: bahan yang kekurangan > 0, jumlahDiminta = kekurangan; user bisa edit/hapus/tambah baris). PO harus status `disetujui`+.
- **Integrasi Tahap 1**: `createBarangKeluar` terima `permintaanBahanId?` opsional; form barang keluar dapat ComboSelect "Permintaan Bahan (opsional)" berisi PB disetujui — memilih PB prefill tujuan `"<nomor PB> / <nomor PO>"`.
- Roles: create/update/submit = owner+admin_produksi; approve/tolak = owner+admin_gudang (gudang yang menyiapkan); read semua.

## DDL (⚡ via MCP)

Enum `pb_status`; tabel `permintaan_bahan` (nomor unique, po FK, tanggal, tanggal_dibutuhkan, status, catatan, created/approved, soft delete) + `permintaan_bahan_detail` (permintaan FK, bahan FK, kebutuhan numeric snapshot, jumlah_diminta numeric, jumlah_disetujui numeric nullable) + index; `ALTER TABLE barang_keluar ADD COLUMN permintaan_bahan_id uuid REFERENCES permintaan_bahan(id)`.

## File

- `src/lib/schemas/permintaan-bahan.ts` — header (poId, tanggal, tanggalDibutuhkan?, catatan?) + details[] (bahanId, kebutuhan, jumlahDiminta > 0).

- `/produksi/permintaan-bahan`: list, `/baru?po=<id>` (prefill estimasi), `/[id]` detail (progress dikeluarkan + aksi per status).

- Patch `src/services/barang-keluar.ts` (kolom baru) + `BarangKeluarForm` (ComboSelect PB opsional) + `src/db/schema.ts`.
