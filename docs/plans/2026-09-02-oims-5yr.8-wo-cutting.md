# Plan: Work Order Cutting (oims-5yr.8)

> PRD Tahap 2 §12–13. Issue `oims-5yr.8`, depends 5yr.7. **Dieksekusi langsung Claude.**

## Keputusan desain

- Nomor `WO-CUT-YYYYMM-NNNN` via `generateDocNumber` (prefix "WO-CUT", tabel `work_order_cutting`).
- Status enum `wo_status` 7 nilai PRD: draft → siap_dikerjakan → sedang_dikerjakan ⇄ ditunda → selesai_sebagian/selesai → diverifikasi (owner). Transisi manual via tombol aksi; label progres hasil (pcs baik vs target) DERIVED dari hasil_cutting (5yr.10), bukan kolom.
- Detail per varian: `varian_id` + `target_cutting` int. Prefill dari PO detail (rencana cutting = ceil(target×(1+tol))) saat pilih PO — editable.
- Header teknis cutting: meja_cutting text, jumlah_layer int, panjang_marker numeric (meter), lebar_kain numeric (cm), nomor_pola text — semua nullable (diisi bertahap).
- PIC = FK users nullable (reuse `listPicOptions`).
- PO yang bisa dibuatkan WO: status disetujui+ (disetujui/menunggu_bahan/bahan_disiapkan/sedang_cutting).
- Halaman `/produksi/wo-cutting`: list + `/baru` + `/[id]` detail = **hub cutting** (info + target per varian + section pemakaian bahan 5yr.9 + section hasil cutting 5yr.10) + `/[id]/edit` (draft only).
- Roles: write = owner+admin_produksi; verifikasi = owner; read semua.
