## Context

Penyesuaian stok = koreksi selisih stok fisik vs sistem (opname), butuh approval owner (PRD lanjutan). Flow:
1. Admin gudang **request** penyesuaian: pilih bahan, isi kuantitas fisik (setelah), alasan. Sistem hitung selisih. Status `pending`.
2. Owner **approve/reject**. Approve → append mutasi (tipe `penyesuaian`, kuantitas = selisih signed) + update stok. Reject → status `rejected`, no mutasi.

Schema `penyesuaianStok` sudah ada: `nomorDokumen (PS-...), bahanId, kuantitasSebelum, kuantitasSetelah, selisih, alasan, status, requestedBy, approvedBy, approvedAt, tanggal`.

### requestPenyesuaian — status pending, NO mutasi
```typescript
export async function requestPenyesuaian(input: PenyesuaianInput) {
  const user = await requireRole(["owner", "admin_gudang"]);
  const [s] = await db.select().from(stok).where(eq(stok.bahanId, input.bahanId)).limit(1);
  const sebelum = Number(s?.kuantitas ?? 0);
  const selisih = input.kuantitasSetelah - sebelum;
  const nomorDokumen = await generateDocNumber("PS", "penyesuaian_stok");

  const [ps] = await db.insert(penyesuaianStok).values({
    nomorDokumen, bahanId: input.bahanId,
    kuantitasSebelum: String(sebelum), kuantitasSetelah: String(input.kuantitasSetelah),
    selisih: String(selisih), alasan: input.alasan, status: "pending",
    requestedBy: user.id, tanggal: new Date(input.tanggal),
  }).returning();
  await writeAudit("CREATE", ps.id, null, ps, user.id);
  return { data: ps };
}
```

### approvePenyesuaian — OWNER only, append mutasi + update stok (atomik)
```typescript
export async function approvePenyesuaian(id: string) {
  const user = await requireRole(["owner"]);  // hanya owner
  return db.transaction(async (tx) => {
    const [ps] = await tx.select().from(penyesuaianStok).where(eq(penyesuaianStok.id, id)).limit(1);
    if (!ps) return { error: "Penyesuaian tidak ditemukan" };
    if (ps.status !== "pending") return { error: "Sudah diproses" };

    // update status
    const [approved] = await tx.update(penyesuaianStok).set({
      status: "approved", approvedBy: user.id, approvedAt: new Date(),
    }).where(eq(penyesuaianStok.id, id)).returning();

    // append mutasi (selisih signed)
    await tx.insert(mutasiStok).values({
      bahanId: ps.bahanId, tipe: "penyesuaian", kuantitas: ps.selisih,
      penyesuaianId: ps.id, createdBy: user.id,
    });
    // update stok cache ke kuantitasSetelah (turunan dari mutasi)
    await tx.update(stok).set({ kuantitas: ps.kuantitasSetelah, updatedAt: new Date() })
      .where(eq(stok.bahanId, ps.bahanId));

    await tx.insert(auditLog).values({
      userId: user.id, aksi: "APPROVE", tabel: "penyesuaian_stok", recordId: id,
      dataBefore: JSON.stringify(ps), dataAfter: JSON.stringify(approved),
    });
    return { data: approved };
  });
}
```
