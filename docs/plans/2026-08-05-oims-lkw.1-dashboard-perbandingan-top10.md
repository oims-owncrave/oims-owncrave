## Task 1 — Service: 2 fungsi baru

File: `src/services/dashboard.ts`

### `getPerbandinganPeriode()`
Return `{ bulanIni: number, bulanLalu: number, delta: number, persen: number }` — total transaksi (masuk+keluar) bulan ini vs lalu.
- 1 query subquery (pola getDashboardStats): count barang_masuk + barang_keluar untuk `date_trunc('month', now())` dan bulan sebelumnya (`date_trunc('month', now()) - interval '1 month'`).
- `delta = bulanIni - bulanLalu`, `persen = bulanLalu > 0 ? (delta/bulanLalu*100) : 0`.
- `requireRole` sama seperti getDashboardStats.

### `getTop10BahanKeluar()`
Return `Array<{ bahanId, kode, nama, satuanSingkatan, totalKeluar: number }>` — 10 bahan kuantitas keluar terbanyak.
- Query: `SUM(bkd.kuantitas)` FROM barang_keluar_detail bkd JOIN barang_keluar bk (filter periode — default all-time atau bulan ini, putuskan: **all-time** lebih informatif) JOIN bahan + satuan, GROUP BY bahan, ORDER BY total DESC LIMIT 10, WHERE bahan.deleted_at IS NULL.
- `requireRole` sama.
