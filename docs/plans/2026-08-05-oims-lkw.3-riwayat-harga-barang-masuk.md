## Task 1 — Service: getRiwayatHargaBahan

File: `src/services/barang-masuk.ts` (atau `bahan.ts`)
```ts
export async function getRiwayatHargaBahan(bahanId: string): Promise<Array<{ tanggal: Date; hargaSatuan: string }>> {
  await requireRole([...]);  // pola existing
  return db.select({ tanggal: barangMasuk.tanggal, hargaSatuan: barangMasukDetail.hargaSatuan })
    .from(barangMasukDetail)
    .innerJoin(barangMasuk, eq(barangMasukDetail.barangMasukId, barangMasuk.id))
    .where(eq(barangMasukDetail.bahanId, bahanId))
    .orderBy(desc(barangMasuk.tanggal))
    .limit(5);
}
```

## Task 2 — Hook

File: `src/hooks/useRiwayatHarga.ts` (baru)
```ts
export function useRiwayatHarga(bahanId: string | null) {
  return useQuery({
    queryKey: ["riwayat-harga", bahanId],
    queryFn: () => getRiwayatHargaBahan(bahanId!),
    enabled: !!bahanId,   // hanya fetch kalau bahan dipilih
    staleTime: 60_000,
  });
}
```

## Task 3 — Tampilkan hint di form

File: `BarangMasukForm.tsx`
- Di tiap row detail, saat `row?.bahanId` ada → panggil `useRiwayatHarga(row.bahanId)`.
  - **Catatan React hooks:** hook tak boleh di dalam `.map` langsung. Solusi: ekstrak row jadi komponen `<DetailRow>` sendiri (tiap row = 1 komponen, panggil hook di dalamnya). Ini refactor kecil row detail jadi komponen.
- Di bawah Input "Harga Satuan": render hint kecil kalau ada riwayat:
  - `"Terakhir: Rp 55.000 (12 Jul) · Rp 50.000 (5 Jul)"` — format 2-3 terakhir, `text-xs text-dark-5 dark:text-dark-6`.
  - Kalau `data.length === 0` (bahan baru) → "Belum ada riwayat harga" atau tak tampil.
  - Loading → skip/spinner kecil.
- **Opsional (nice-to-have, boleh skip):** klik salah satu harga → `setValue(detail.i.hargaSatuan, harga)`. Kalau dikerjakan, pakai button kecil.
