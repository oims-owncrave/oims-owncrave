## Context

User perlu insert banyak data master sekaligus (puluhan/ratusan baris) tanpa ketik satu-satu di form. Solusi: **import batch via upload Excel (.xlsx)** + sediakan **template .xlsx** yang bisa didownload untuk diisi.

Keputusan (dikonfirmasi user):
- **Format: .xlsx** (bukan CSV). Alasan: user awam garmen tahunya Excel; CSV punya jebakan koma/delimiter locale ID/leading-zero. Butuh 1 dependency baru: **`xlsx` (SheetJS)** — justified, ratusan baris kalau ditulis sendiri.
- **Template = KOSONG**: hanya baris header kolom + 1-2 baris contoh (bukan pre-fill data existing).
- **Import MURNI insert baru** (bukan upsert/update massal).
- **Error = all-or-nothing**: ada 1 baris gagal → rollback SEMUA, tampilkan daftar baris gagal + alasan. User perbaiki file, upload ulang. Tidak ada data setengah masuk (cocok untuk import murni-insert; partial bikin duplikat saat re-upload).

Scope Issue A = **infra generik + 3 entitas flat tanpa FK**: kategori, satuan, supplier. Bahan (FK resolve + transaction + auto-kode) dipisah ke oims-jpn.16 supaya A kelihatan jalan dulu; B nebeng infra ini.

Skema 3 entitas (dari `src/db/schema.ts`, JANGAN ubah):
- `kategori`: kode (≤20), nama (≤100), isActive. Partial unique `kategori_kode_active_unique` on kode WHERE deleted_at IS NULL.
- `satuan`: nama (≤50), singkatan (≤10), isActive. Partial unique `satuan_nama_active_unique` on nama.
- `supplier`: kode (≤20), nama (≤150), kontak? (≤100), alamat? (≤300), isActive. Partial unique `supplier_kode_active_unique` on kode.

Zod schema + create action sudah ada per entitas (`src/lib/schemas/*`, `src/services/*`) — reuse schema untuk validasi, tapi insert lewat **batch action baru** (satu transaksi), bukan loop `createKategori` (loop = N transaksi, gagal tengah = data setengah masuk).

## Task 2 — Parser xlsx (client)

**File:** `src/lib/import/parse-xlsx.ts`

```typescript
import * as XLSX from "xlsx";
import type { ImportColumn } from "./types";

// Baca File .xlsx -> array baris object { [key]: string }.
// Cocokkan header Excel (case-insensitive, trim) ke ImportColumn.key.
// Baris contoh (baris pertama data) DIBUANG kalau match nilai example semua -> lihat opsi drop di modal.
export async function parseXlsx(
  file: File,
  columns: ImportColumn[],
): Promise<{ rows: Record<string, string>[]; error?: string }> {
  const buf = await file.arrayBuffer();
  const wb = XLSX.read(buf, { type: "array" });
  const sheet = wb.Sheets[wb.SheetNames[0]];
  if (!sheet) return { rows: [], error: "File Excel kosong / tidak ada sheet." };

  // header: 1 -> array of array (baris pertama = header). raw: false -> semua string.
  const matrix = XLSX.utils.sheet_to_json<string[]>(sheet, {
    header: 1,
    raw: false,
    defval: "",
  });
  if (matrix.length < 2) return { rows: [], error: "File tidak berisi data (hanya header)." };

  const headerRow = (matrix[0] ?? []).map((h) => String(h).trim().toLowerCase());
  // map index kolom Excel -> key internal
  const colIndex: Record<string, number> = {};
  for (const col of columns) {
    const idx = headerRow.indexOf(col.header.toLowerCase());
    if (idx === -1 && col.required) {
      return { rows: [], error: `Kolom wajib "${col.header}" tidak ditemukan di header Excel.` };
    }
    colIndex[col.key] = idx;
  }

  const rows: Record<string, string>[] = [];
  for (let r = 1; r < matrix.length; r++) {
    const raw = matrix[r] ?? [];
    // skip baris kosong total
    if (raw.every((c) => String(c).trim() === "")) continue;
    const obj: Record<string, string> = {};
    for (const col of columns) {
      const idx = colIndex[col.key];
      obj[col.key] = idx >= 0 ? String(raw[idx] ?? "").trim() : "";
    }
    rows.push(obj);
  }
  return { rows };
}
```

> **Baris contoh:** template punya 1-2 baris contoh. User mungkin biarkan atau hapus. Strategi paling aman: di template, tandai baris contoh dengan nilai `example` yang jelas placeholder (mis. "CONTOH-001"). Parser TIDAK auto-drop (bisa salah buang data asli); sebagai gantinya, validasi biasa akan menolak duplikat / jelasnya user hapus baris contoh sebelum isi. **Instruksikan di template** (baris komentar / kolom pertama contoh diberi teks "HAPUS BARIS INI"). Simpel, tanpa heuristik rapuh.

## Task 3 — Template generator (client)

**File:** `src/lib/import/template.ts`

```typescript
import * as XLSX from "xlsx";
import type { ImportColumn } from "./types";

// Generate + download file .xlsx template: baris header + 1 baris contoh.
export function downloadTemplate(
  filename: string,
  columns: ImportColumn[],
) {
  const header = columns.map((c) => c.header);
  const example = columns.map((c) => c.example);
  const aoa = [header, example];

  const ws = XLSX.utils.aoa_to_sheet(aoa);
  // lebar kolom biar kebaca
  ws["!cols"] = columns.map((c) => ({ wch: Math.max(c.header.length, 14) }));

  const wb = XLSX.utils.book_new();
  XLSX.utils.book_append_sheet(wb, ws, "Template");
  XLSX.writeFile(wb, filename.endsWith(".xlsx") ? filename : `${filename}.xlsx`);
}
```

> Reuse pola download dari `src/lib/export-csv.ts` TIDAK diperlukan — `XLSX.writeFile` sudah trigger download browser sendiri. `export-csv.ts` tetap dipakai untuk export CSV (fitur lain), tidak disentuh.

## Task 4 — Batch Server Actions (all-or-nothing)

**File:** `src/services/import.ts`

Pola per entitas: validasi SEMUA row dulu (Zod + dup di dalam file + dup vs DB aktif), kalau ada error → return errors tanpa insert. Kalau bersih → `db.transaction` insert semua + audit per row.

```typescript
"use server";

import { and, eq, isNull, inArray } from "drizzle-orm";
import { db } from "@/db";
import { kategori, satuan, supplier, auditLog } from "@/db/schema";
import { kategoriSchema } from "@/lib/schemas/kategori";
import { satuanSchema } from "@/lib/schemas/satuan";
import { supplierSchema } from "@/lib/schemas/supplier";
import { requireRole } from "@/lib/auth";
import type { ImportResult, RowError } from "@/lib/import/types";

// contoh untuk KATEGORI — supplier & satuan analog (beda field + kolom unik)
export async function importKategoriBatch(
  rows: Record<string, string>[],
): Promise<ImportResult> {
  const user = await requireRole(["owner", "admin_gudang"]);
  if (!rows.length) return { error: "Tidak ada data untuk diimport." };

  const errors: RowError[] = [];
  const parsed: { kode: string; nama: string; isActive: boolean }[] = [];
  const kodeSeen = new Set<string>();

  rows.forEach((raw, i) => {
    const rowNum = i + 1;
    const input = {
      kode: raw.kode ?? "",
      nama: raw.nama ?? "",
      isActive: true, // import default aktif
    };
    const res = kategoriSchema.safeParse(input);
    if (!res.success) {
      errors.push({ row: rowNum, message: res.error.issues[0]?.message ?? "Data tidak valid" });
      return;
    }
    // duplikat dalam file
    const k = res.data.kode.toLowerCase();
    if (kodeSeen.has(k)) {
      errors.push({ row: rowNum, message: `Kode "${res.data.kode}" duplikat di dalam file` });
      return;
    }
    kodeSeen.add(k);
    parsed.push(res.data);
  });

  // duplikat vs DB (hanya baris aktif — partial unique)
  if (parsed.length) {
    const kodes = parsed.map((p) => p.kode);
    const existing = await db
      .select({ kode: kategori.kode })
      .from(kategori)
      .where(and(inArray(kategori.kode, kodes), isNull(kategori.deletedAt)));
    const existSet = new Set(existing.map((e) => e.kode.toLowerCase()));
    parsed.forEach((p, i) => {
      if (existSet.has(p.kode.toLowerCase())) {
        // cari row asli untuk nomor baris yang akurat
        const rowNum = rows.findIndex((r) => (r.kode ?? "").trim().toLowerCase() === p.kode.toLowerCase()) + 1;
        errors.push({ row: rowNum, message: `Kode "${p.kode}" sudah ada di database` });
      }
    });
  }

  if (errors.length) return { errors: errors.sort((a, b) => a.row - b.row) };

  // all-or-nothing insert
  await db.transaction(async (tx) => {
    for (const p of parsed) {
      const [row] = await tx.insert(kategori).values(p).returning();
      await tx.insert(auditLog).values({
        userId: user.id,
        aksi: "CREATE",
        tabel: "kategori",
        recordId: row.id,
        dataBefore: null,
        dataAfter: JSON.stringify(row),
      });
    }
  });

  return { inserted: parsed.length };
}

// importSupplierBatch — sama, tapi: schema supplierSchema, kolom kode+nama+kontak?+alamat?,
//   kontak/alamat -> null kalau "", unik = kode, tabel "supplier".
// importSatuanBatch — schema satuanSchema, kolom nama+singkatan, unik = NAMA (bukan kode!),
//   dedup + cek DB pakai nama, tabel "satuan".
```

> **PENTING satuan:** unik-nya `nama`, BUKAN kode (satuan tidak punya kode). Ganti semua cek `kode` → `nama` di importSatuanBatch.
> **PENTING supplier:** `kontak`/`alamat` opsional → `raw.kontak || null`. inArray guard sama (kode).
> **Audit dalam transaksi:** tulis auditLog via `tx` (bukan `db`) supaya ikut rollback kalau gagal.
> **`inArray` limit:** master import realistis puluhan-ratusan row; `inArray` aman. Kalau >~100 UUID/kode, chunk (lihat CLAUDE.md cross-project lesson). Untuk kode string pendek, ratusan masih di bawah URL limit PostgREST — tapi ini pakai Drizzle langsung (bukan PostgREST), jadi aman.

Flow modal (ikut `_pola-master-crud.md` §5 — container z-70, backdrop fixed):

3. Pilih file → `parseXlsx` → simpan rows + tampilkan "N baris terbaca".
4. Tombol "Import" → `action(rows)` (via `useMutation`/`mutateAsync`):
   - `result.inserted` → `toast.success("N data diimport", toastStyles.primary)` + `onSuccess()`.
   - `result.errors` → tampilkan daftar di modal: `Baris {row}: {message}` (list scroll, maks tampil). Tidak close, user perbaiki file.

5. Button submit pakai `loading={mutation.isPending}` (pola §5).

> **File-upload component:** tidak ada di codebase. Buat inline di modal ini (input file + label bergaya). Jangan bikin komponen upload generik terpisah — YAGNI, cuma dipakai di sini.
