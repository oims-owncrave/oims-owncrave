# Plan — oims-g05.8: Card action kebab menu (mobile)

**Tanggal:** 2026-08-05 · **Issue:** oims-g05.8 (feature, P3) · **Parent:** oims-g05
**Depends:** g05.5 (card view, sudah done) · Terpusat di table kit

## Context

Card view mobile (g05.5): aksi baris (edit/hapus) render sebagai **icon inline** di bawah card (border-top + icon berjejer). Owner mau pola mobile umum: **kebab (titik-tiga ⋮) di pojok kanan card → tap → dropdown menu aksi**. Lebih bersih, skalabel, tap aman. Terpusat di `table.tsx` card render (semua tabel ikut, 0 perubahan per-tabel).

## Fakta terverifikasi

- `src/components/ui/table/table.tsx` card render ~line 227: `const actions = roles.filter(r => r.role === "action")`. Line ~285: render `actions.map` sebagai div border-top berisi icon (dari `renderVal` → `TableActions` component tiap tabel).
- `TableActions` (`table-actions.tsx`) — render tiap action sbg icon button (icon, title, onClick, loading). Aksi tabel = `renderCell` kolom aksi yang panggil `<TableActions actions={[...]} />`.
- **Masalah desain:** action di card = hasil `renderVal(col aksi)` = `<TableActions>` (icon berjejer). Untuk kebab, perlu render aksi beda di card — TAPI action item ada di dalam TableActions per-tabel (tak ke-expose ke card level).
- UI kit: `src/components/ui/Dropdown.tsx` (context-based menu, portal) — pakai untuk kebab dropdown.

## Pendekatan

Card tak bisa gampang "buka" action item dari `TableActions` (itu renderCell tabel). 2 opsi:

**Opsi A (recommended, terpusat):** Di card render, bungkus hasil `renderVal(action col)` dalam kebab Dropdown. Yaitu: kebab button (⋮) di pojok kanan atas card → Dropdown → isi = `renderVal(actionCol)` (TableActions existing, tapi tampil vertical dalam dropdown). TableActions perlu prop `layout?: "row" | "menu"` supaya di dropdown render sebagai list item (icon+title) bukan icon-only.

**Opsi B (per-tabel):** tiap tabel expose action list ke card. Lebih banyak kerja. SKIP.

→ **Pakai Opsi A.**

## Task 1 — TableActions: mode menu

File: `table-actions.tsx`
- Tambah prop `variant?: "row" | "menu"` (default "row" = sekarang).
- `variant="menu"`: render tiap action sebagai baris full-width (icon + title text), bukan icon-only button. Buat dropdown item.

## Task 2 — Card kebab di table.tsx

File: `table.tsx` card render
- Ganti blok `actions.length > 0 && (<div border-top>...)` (line ~285):
  - Pindah kebab ke **pojok kanan atas card** (samping title/highlight row).
  - Kebab button (⋮ / MoreVertical lucide) → `<Dropdown>` (UI kit) → isi = render action col dengan `variant="menu"`.
  - Perlu cara pass `variant="menu"` ke TableActions yang di-render via `renderVal`. Karena renderVal panggil `col.renderCell`, dan renderCell tiap tabel bikin `<TableActions>` sendiri — **tak bisa inject variant dari card**.
  - **Solusi:** deteksi action col, render kebab wrapper, DI DALAM dropdown panggil `renderVal(actionCol)` apa adanya (TableActions row tetap, tapi dalam dropdown vertical container `flex-col` — CSS bikin icon jadi list). ATAU tambah context `TableActionsVariant` yang card set ke "menu".
  - **Paling bersih:** React context `CardActionContext` — card set `variant="menu"`, TableActions baca context. Kalau tak ada context (desktop table) → "row".

## Task 3 — Ikon + posisi

- Kebab: `MoreVertical` (lucide) size 18, pojok kanan atas card, `text-dark-5`.
- Dropdown align right. Dark mode token.
- Desktop table TAK berubah (kebab hanya di card, `sm:hidden` scope card sudah handle).
