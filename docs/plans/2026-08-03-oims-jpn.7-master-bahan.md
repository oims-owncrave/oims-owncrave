## Context

Master bahan = data bahan baku (kain, benang, kancing, dst — PRD §9). Prerequisite SEMUA transaksi (barang masuk/keluar merujuk bahan).

Schema `bahan` **sudah ada** (`src/db/schema.ts`) — JANGAN ubah:
```typescript
bahan: {
  id, kode (unique, auto: BH-[KODE_KATEGORI]-[NOMOR]), nama,
  kategoriId (FK, notNull), satuanId (FK, notNull),
  stokMinimum (numeric 15,3), hargaRataRata (numeric 15,2, default 0),
  isActive, createdAt, updatedAt, deletedAt
}
```

**Beda kritis dari master lain:**
1. **`kode` auto-generate** — format `BH-[KODE_KATEGORI]-[NOMOR]`, mis. `BH-KTN-001`. Bukan input user. Generate di Server Action berdasarkan kategori terpilih + count bahan existing di kategori itu.
2. **`hargaRataRata` READ-ONLY di form** — di-update otomatis oleh barang masuk (weighted average). Form create: default 0. Form edit: TAMPILKAN tapi disabled (info saja).
3. **`stokMinimum`** — input user (numeric, untuk alert stok kritis).
4. **FK kategori + satuan** — dropdown dari data existing (pakai ComboSelect atau Select, ambil dari listKategori/listSatuan yang aktif).

## Task 2 — Server Actions (`src/services/bahan.ts`)

Pola kategori + guard `requireRole` (dari `src/lib/auth.ts` — jpn.3 harus selesai). Beda:

### Auto-generate kode
```typescript
async function generateKodeBahan(kategoriId: string): Promise<string> {
  const [kat] = await db.select({ kode: kategori.kode }).from(kategori)
    .where(eq(kategori.id, kategoriId)).limit(1);
  if (!kat) throw new Error("Kategori tidak ditemukan");

  // count bahan di kategori ini (termasuk soft-deleted, biar nomor tidak reuse)
  const existing = await db.select({ id: bahan.id }).from(bahan)
    .where(eq(bahan.kategoriId, kategoriId));
  const nomor = String(existing.length + 1).padStart(3, "0");
  return `BH-${kat.kode}-${nomor}`;
}
```

### listBahan — JOIN kategori + satuan untuk display
```typescript
export async function listBahan() {
  await requireRole(["owner", "admin_gudang", "admin_produksi", "keuangan", "viewer"]);
  return db
    .select({
      id: bahan.id, kode: bahan.kode, nama: bahan.nama,
      kategoriId: bahan.kategoriId, kategoriNama: kategori.nama,
      satuanId: bahan.satuanId, satuanNama: satuan.nama, satuanSingkatan: satuan.singkatan,
      stokMinimum: bahan.stokMinimum, hargaRataRata: bahan.hargaRataRata,
      isActive: bahan.isActive,
    })
    .from(bahan)
    .leftJoin(kategori, eq(bahan.kategoriId, kategori.id))
    .leftJoin(satuan, eq(bahan.satuanId, satuan.id))
    .where(isNull(bahan.deletedAt))
    .orderBy(bahan.kode);
}
```

### createBahan — generate kode, requireRole owner+admin_gudang
```typescript
export async function createBahan(input: BahanInput) {
  const user = await requireRole(["owner", "admin_gudang"]);
  const kode = await generateKodeBahan(input.kategoriId);
  const [created] = await db.insert(bahan).values({
    kode, nama: input.nama, kategoriId: input.kategoriId, satuanId: input.satuanId,
    stokMinimum: String(input.stokMinimum), isActive: input.isActive,
    // hargaRataRata default 0 dari schema
  }).returning();
  // buat baris stok awal 0
  await db.insert(stok).values({ bahanId: created.id, kuantitas: "0" });
  await writeAudit("CREATE", created.id, null, created, user.id);
  return { data: created };
}
```
> **PENTING:** saat create bahan, buat juga baris `stok` (kuantitas 0) — supaya barang masuk/keluar nanti bisa update lewat mutasi.

### updateBahan — TIDAK boleh ubah kode/hargaRataRata
```typescript
export async function updateBahan(id: string, input: Omit<BahanInput, never>) {
  const user = await requireRole(["owner", "admin_gudang"]);
  const [before] = await db.select().from(bahan).where(eq(bahan.id, id)).limit(1);
  if (!before) return { error: "Bahan tidak ditemukan" };
  // kode TIDAK diubah walau kategori berubah (kode = identitas permanen)
  const [updated] = await db.update(bahan).set({
    nama: input.nama, kategoriId: input.kategoriId, satuanId: input.satuanId,
    stokMinimum: String(input.stokMinimum), isActive: input.isActive,
    updatedAt: new Date(),
  }).where(eq(bahan.id, id)).returning();
  await writeAudit("UPDATE", id, before, updated, user.id);
  return { data: updated };
}
```

### softDeleteBahan — guard: cek transaksi
```typescript
export async function softDeleteBahan(id: string) {
  const user = await requireRole(["owner", "admin_gudang"]);
  // guard: bahan tak boleh dihapus jika ada di barang masuk/keluar detail
  const usedMasuk = await db.select({ id: barangMasukDetail.id }).from(barangMasukDetail)
    .where(eq(barangMasukDetail.bahanId, id)).limit(1);
  const usedKeluar = await db.select({ id: barangKeluarDetail.id }).from(barangKeluarDetail)
    .where(eq(barangKeluarDetail.bahanId, id)).limit(1);
  if (usedMasuk.length || usedKeluar.length) {
    return { error: "Bahan tidak bisa dihapus — sudah punya transaksi. Nonaktifkan saja." };
  }
  const [before] = await db.select().from(bahan).where(eq(bahan.id, id)).limit(1);
  const [updated] = await db.update(bahan).set({ deletedAt: new Date() }).where(eq(bahan.id, id)).returning();
  await writeAudit("DELETE", id, before, updated, user.id);
  return { data: updated };
}
```

Import tambahan: `kategori, satuan, stok, barangMasukDetail, barangKeluarDetail` dari schema.
