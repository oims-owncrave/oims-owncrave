# Plan: Varian Produk — matrix warna × ukuran + SKU auto (oims-5yr.2)

> PRD Tahap 2 §6. Issue: `oims-5yr.2`. Depends: `oims-5yr.1` (master produk).
> Pola UI: `docs/plans/_pola-master-crud.md` untuk konvensi umum (modal, toast, soft delete).

## Konteks

Varian = kombinasi produk × warna × ukuran, tiap varian punya SKU. Dipakai PO produksi (detail per SKU), hasil cutting, bundling. Referensi app lama: `Model {colors[], sizes[]}` matrix tanpa SKU formal (referensi §10) — di sini dinormalkan jadi baris varian + SKU.

Keputusan desain:
- **Varian dikelola dari halaman produk**, BUKAN route sendiri. Halaman list produk dapat aksi baru "Varian" (icon `Layers`) → buka `/produksi/produk/[id]` (detail produk + tabel varian). Nav tidak berubah.
- `warna` pakai FK ke master `warna` Tahap 1 (sudah ada). `ukuran` = text bebas dengan datalist saran `XS S M L XL XXL 3XL`. `jenis_kelamin` text nullable (`Pria`/`Wanita`/`Unisex`).
- **SKU auto-generate**: `[KODE_PRODUK]-[KODE_WARNA]-[UKURAN]` (uppercase, contoh `NJK-HTM-M`), editable di form sebelum simpan. Unik partial.
- **Generator matrix**: form "Tambah Varian" mendukung multi-select warna + multi-select ukuran → server bikin semua kombinasi sekaligus (skip yang sudah ada, laporkan yang di-skip).

## Task 1 — DB Migration ⚡ CLAUDE VIA MCP (sudah selesai)

```sql
CREATE TABLE varian_produk (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  produk_id uuid NOT NULL REFERENCES produk(id),
  warna_id uuid NOT NULL REFERENCES warna(id),
  ukuran text NOT NULL,
  jenis_kelamin text,
  sku text NOT NULL,
  is_active boolean NOT NULL DEFAULT true,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  deleted_at timestamptz
);
CREATE UNIQUE INDEX varian_sku_active_unique ON varian_produk (sku) WHERE deleted_at IS NULL;
CREATE UNIQUE INDEX varian_kombinasi_active_unique ON varian_produk (produk_id, warna_id, ukuran) WHERE deleted_at IS NULL;
CREATE INDEX varian_produk_idx ON varian_produk (produk_id);
```

## Task 2 — schema.ts ⚡ CLAUDE (sudah selesai)

Setelah `produk`:

```ts
export const varianProduk = pgTable(
  "varian_produk",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    produkId: uuid("produk_id").notNull().references(() => produk.id),
    warnaId: uuid("warna_id").notNull().references(() => warna.id),
    ukuran: text("ukuran").notNull(),
    jenisKelamin: text("jenis_kelamin"),
    sku: text("sku").notNull(), // auto [KODE_PRODUK]-[KODE_WARNA]-[UKURAN], unik partial
    isActive: boolean("is_active").notNull().default(true),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp("updated_at", { withTimezone: true }).notNull().defaultNow(),
    deletedAt: timestamp("deleted_at", { withTimezone: true }),
  },
  (t) => [
    uniqueIndex("varian_sku_active_unique").on(t.sku).where(isNull(t.deletedAt)),
    uniqueIndex("varian_kombinasi_active_unique").on(t.produkId, t.warnaId, t.ukuran).where(isNull(t.deletedAt)),
    index("varian_produk_idx").on(t.produkId),
  ]
);
export type VarianProduk = typeof varianProduk.$inferSelect;
```

## Task 4 — Server Actions

`src/services/varian-produk.ts`:
- `getProdukDetail(produkId)` — produk + list varian (join warna untuk nama/kode), filter `isNull(deletedAt)` dua-duanya.
- `generateVarian(produkId, values)` — dalam `db.transaction`:
  1. Ambil produk (kode) + warna terpilih (kode).
  2. Loop kombinasi warnaIds × ukuran → skip kombinasi yang sudah ada aktif (query existing sekali di awal, cek via Set `warnaId|ukuran`).
  3. SKU = `${produk.kode}-${warna.kode}-${ukuran}`.toUpperCase(). Guard SKU unik aktif (pre-fetch existing SKU produk ini — kolisi lintas-produk praktis tak mungkin karena prefix kode produk unik).
  4. Insert batch + `writeAudit("CREATE","varian_produk", ...)` per baris.
  5. Return `{ created: n, skipped: string[] }` — skipped = label kombinasi yang sudah ada.
- `updateVarian(id, values)` — guard SKU unik (exclude self), audit UPDATE.
- `softDeleteVarian(id)` — set deletedAt + audit DELETE. (Guard referensi PO ditambah di oims-5yr.4.)
