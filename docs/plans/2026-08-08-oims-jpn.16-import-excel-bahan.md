## Context

Perluas fitur import Excel ke entitas **bahan**. Bahan beda kelas dari master flat (kategori/satuan/supplier) — butuh logika tambahan yang TIDAK ada di oims-jpn.15:

1. **FK resolve.** Excel diisi user awam → TIDAK boleh minta UUID. Kolom pakai teks manusiawi: nama/kode kategori, nama/singkatan satuan, nama warna. Server **resolve teks → UUID** per baris. Gagal ketemu (mis. kategori "Katunn" typo) = error baris.
2. **Kode auto-generate.** `bahan.kode` = `BH-{KATEGORI_KODE}-{NNN}` (generate server, lihat `src/services/bahan.ts:38`). User TIDAK isi kode di Excel.
3. **Insert transaksional + stok row.** Tiap bahan WAJIB punya baris `stok` (kuantitas 0, cache; sumber kebenaran `mutasi_stok`). `createBahan` existing sudah pola ini (`src/services/bahan.ts:55-73`). Batch import harus replikasi dalam 1 transaksi besar (all-or-nothing).
4. **Numeric.** `stokMinimum` (numeric 15,3), `hargaAwal` → `hargaRataRata` (numeric 15,2), boleh 0. Parse string Excel → number → String() untuk Drizzle.

Semua aturan Issue A tetap: import murni insert, all-or-nothing rollback, audit per row, ikut CLAUDE.md.

Skema `bahan` (dari `src/db/schema.ts:88`, JANGAN ubah): nama, kategoriId (FK notNull), satuanId (FK notNull), warnaId (FK nullable), stokMinimum (default 0), hargaRataRata (default 0), isActive. Partial unique `bahan_kode_active_unique` on kode.

## Task 1 — FK resolver + batch action

**File:** `src/services/import.ts` (tambah `importBahanBatch` ke file dari Issue A)

Strategi resolve efisien: **pre-fetch semua master aktif SEKALI** (bukan query per baris), buat lookup Map, resolve in-memory.

```typescript
import { bahan, stok, kategori, satuan, warna, auditLog } from "@/db/schema";
import { bahanSchema } from "@/lib/schemas/bahan";

export async function importBahanBatch(
  rows: Record<string, string>[],
): Promise<ImportResult> {
  const user = await requireRole(["owner", "admin_gudang"]);
  if (!rows.length) return { error: "Tidak ada data untuk diimport." };

  // pre-fetch master aktif -> Map lookup (lowercase key)
  const [kats, sats, wrns] = await Promise.all([
    db.select().from(kategori).where(isNull(kategori.deletedAt)),
    db.select().from(satuan).where(isNull(satuan.deletedAt)),
    db.select().from(warna).where(isNull(warna.deletedAt)),
  ]);
  // kategori: match by kode ATAU nama
  const katMap = new Map<string, { id: string; kode: string }>();
  kats.forEach((k) => {
    katMap.set(k.kode.toLowerCase(), { id: k.id, kode: k.kode });
    katMap.set(k.nama.toLowerCase(), { id: k.id, kode: k.kode });
  });
  const satMap = new Map<string, string>(); // key -> id, match nama atau singkatan
  sats.forEach((s) => {
    satMap.set(s.nama.toLowerCase(), s.id);
    satMap.set(s.singkatan.toLowerCase(), s.id);
  });
  const wrnMap = new Map<string, string>();
  wrns.forEach((w) => wrnMap.set(w.nama.toLowerCase(), w.id));

  const errors: RowError[] = [];
  type Resolved = {
    nama: string; kategoriId: string; kategoriKode: string;
    satuanId: string; warnaId: string | null;
    stokMinimum: number; hargaAwal: number;
  };
  const parsed: Resolved[] = [];

  rows.forEach((raw, i) => {
    const rowNum = i + 1;
    const nama = (raw.nama ?? "").trim();
    const katKey = (raw.kategori ?? "").trim().toLowerCase();
    const satKey = (raw.satuan ?? "").trim().toLowerCase();
    const wrnKey = (raw.warna ?? "").trim().toLowerCase();

    if (!nama) { errors.push({ row: rowNum, message: "Nama bahan wajib diisi" }); return; }

    const kat = katMap.get(katKey);
    if (!kat) { errors.push({ row: rowNum, message: `Kategori "${raw.kategori}" tidak ditemukan / tidak aktif` }); return; }

    const satId = satMap.get(satKey);
    if (!satId) { errors.push({ row: rowNum, message: `Satuan "${raw.satuan}" tidak ditemukan / tidak aktif` }); return; }

    let warnaId: string | null = null;
    if (wrnKey) {
      const w = wrnMap.get(wrnKey);
      if (!w) { errors.push({ row: rowNum, message: `Warna "${raw.warna}" tidak ditemukan / tidak aktif` }); return; }
      warnaId = w;
    }

    const stokMinimum = raw.stokMinimum ? Number(raw.stokMinimum) : 0;
    const hargaAwal = raw.hargaAwal ? Number(raw.hargaAwal) : 0;
    if (Number.isNaN(stokMinimum) || stokMinimum < 0) { errors.push({ row: rowNum, message: `Stok Minimum "${raw.stokMinimum}" tidak valid` }); return; }
    if (Number.isNaN(hargaAwal) || hargaAwal < 0) { errors.push({ row: rowNum, message: `Harga Awal "${raw.hargaAwal}" tidak valid` }); return; }

    // validasi final lewat zod (nama length dsb)
    const res = bahanSchema.safeParse({
      nama, kategoriId: kat.id, satuanId: satId, warnaId,
      stokMinimum, isActive: true, hargaAwal,
    });
    if (!res.success) { errors.push({ row: rowNum, message: res.error.issues[0]?.message ?? "Data tidak valid" }); return; }

    parsed.push({ nama, kategoriId: kat.id, kategoriKode: kat.kode, satuanId: satId, warnaId, stokMinimum, hargaAwal });
  });

  if (errors.length) return { errors: errors.sort((a, b) => a.row - b.row) };

  // all-or-nothing: 1 transaksi besar. kode generate per baris (per kategori, urut).
  await db.transaction(async (tx) => {
    // counter per kategori: ambil count existing (termasuk soft-deleted, pola generateKodeBahan)
    // lalu increment in-memory selama loop supaya kode unik dalam batch.
    const counter = new Map<string, number>();
    for (const p of parsed) {
      let start = counter.get(p.kategoriId);
      if (start === undefined) {
        const existing = await tx.select({ id: bahan.id }).from(bahan).where(eq(bahan.kategoriId, p.kategoriId));
        start = existing.length;
      }
      const next = start + 1;
      counter.set(p.kategoriId, next);
      const kode = `BH-${p.kategoriKode}-${String(next).padStart(3, "0")}`;

      const [row] = await tx.insert(bahan).values({
        kode,
        nama: p.nama,
        kategoriId: p.kategoriId,
        satuanId: p.satuanId,
        warnaId: p.warnaId,
        stokMinimum: String(p.stokMinimum),
        hargaRataRata: String(p.hargaAwal),
        isActive: true,
      }).returning();

      await tx.insert(stok).values({ bahanId: row.id, kuantitas: "0" }); // invariant: tiap bahan punya stok row
      await tx.insert(auditLog).values({
        userId: user.id, aksi: "CREATE", tabel: "bahan",
        recordId: row.id, dataBefore: null, dataAfter: JSON.stringify(row),
      });
    }
  });

  return { inserted: parsed.length };
}
```

> **Kode counter in-memory KRUSIAL:** kalau 3 bahan baru masuk kategori KTN dalam 1 file, `generateKodeBahan` (count DB) akan balikin nomor sama untuk ketiganya → duplikat kode → transaksi gagal. Counter Map increment per kategori dalam loop mencegah ini. Baca `src/services/bahan.ts:38-49` untuk pola asli.
> **JANGAN reuse `createBahan` dalam loop** — itu N transaksi, tiap satu `requireRole` + generate query. Batch = 1 transaksi, resolve/counter in-memory.
> **isActive:** import default aktif (tidak ada kolom di template).
