## Konteks

Gudang barang jadi bukan sekadar master pelengkap — ia **dimensi kunci komposit stok
barang jadi** (`.13`): stok disimpan per `(varian, grade, gudang, batch)` sesuai PRD §25.
Jadi harus ada sebelum stok jadi dibangun.

### Kenapa TIDAK reuse `lokasi_produksi` (oims-eba.3)

`lokasi_produksi` = tempat **kerja** (workshop, tempat vendor menjahit). Gudang barang jadi =
tempat **simpan stok siap jual**. Dimensi berbeda; mencampur keduanya membuat dropdown
"pilih gudang" berisi workshop vendor, dan kunci stok jadi ikut tercemar. Tabel sendiri.

App lama hanya punya **satu** lokasi stok jadi tanpa grade (`referensi §10`: "disederhanakan
(1 lokasi, tanpa grade)"). PRD §27 minta 6 jenis lokasi — kita ikuti PRD karena transfer
antar gudang (`.14`) memang diminta klien.

## Task 1 — Enum + tabel ⚡ CLAUDE VIA MCP (bukan Antigravity)

```ts
export const gudangJenisEnum = pgEnum("gudang_jenis", [
  "gudang_utama", "gudang_online", "toko_offline",
  "studio", "lokasi_sample", "transit",
]);

export const gudangBarangJadi = pgTable(
  "gudang_barang_jadi",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    kode: text("kode").notNull(),                    // BUKAN .unique()
    nama: text("nama").notNull(),
    jenis: gudangJenisEnum("jenis").notNull().default("gudang_utama"),
    alamat: text("alamat"),
    picNama: text("pic_nama"),
    isDefault: boolean("is_default").notNull().default(false),
    isActive: boolean("is_active").notNull().default(true),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp("updated_at", { withTimezone: true }).notNull().defaultNow(),
    deletedAt: timestamp("deleted_at", { withTimezone: true }),
  },
  (t) => [
    uniqueIndex("gudang_bj_kode_active_unique").on(t.kode).where(isNull(t.deletedAt)),
  ]
);
```

### Aturan `isDefault` — tepat satu

Set gudang baru sebagai default → gudang default lama otomatis lepas. Lakukan **dalam satu
transaksi DB**, bukan dua panggilan terpisah:

```ts
await db.transaction(async (tx) => {
  if (input.isDefault) {
    await tx.update(gudangBarangJadi)
      .set({ isDefault: false, updatedAt: new Date() })
      .where(and(eq(gudangBarangJadi.isDefault, true), isNull(gudangBarangJadi.deletedAt)));
  }
  // insert/update gudang ini
});
```

Pola ini sama dengan aktivasi tarif berversi (`tarif_jasa_jahit`, oims-eba.4) yang sudah
lolos smoke test Tahap 3 — contek dari sana.

Wajib lain: filter `isNull(deletedAt)` di semua select, guard kode duplikat aktif,
`writeAudit` tiap CREATE/UPDATE/DELETE.
