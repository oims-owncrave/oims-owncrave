## Context

Master satuan = unit ukur bahan (Meter, Kg, Pcs, Roll — PRD §7). Prerequisite `master bahan` (bahan wajib `satuan_id`).

Schema `satuan` **sudah ada** (`src/db/schema.ts:58-65`) — JANGAN ubah:
```typescript
satuan: { id, nama (unique), singkatan, isActive, createdAt, deletedAt }
```
> Catatan: satuan TIDAK punya `kode` dan `updatedAt` (beda dari kategori). PRD §7 sebut `kode` + `digit desimal` — schema tidak punya → skip, ikut schema.

Aturan: nama unik, singkatan wajib, soft delete + guard (tak boleh hapus jika dipakai bahan), bisa nonaktif.

## Beda dari plan kategori

### Task 1 — Zod (`src/lib/schemas/satuan.ts`)
```typescript
import { z } from "zod";

export const satuanSchema = z.object({
  nama: z.string().min(1, "Nama wajib diisi").max(50),
  singkatan: z.string().min(1, "Singkatan wajib diisi").max(10),
  isActive: z.boolean().default(true),
});

export type SatuanInput = z.infer<typeof satuanSchema>;
```

### Task 2 — Server Actions (`src/services/satuan.ts`)
Sama pola kategori, dengan perbedaan:
- `tabel: "satuan"` di audit
- `listSatuan` order by `satuan.nama`
- Cek unik pakai `satuan.nama` (bukan kode)
- **UPDATE: satuan tidak punya `updatedAt`** — hapus `updatedAt: new Date()` dari `.set()` di updateSatuan
- Guard soft delete: cek `bahan.satuanId`:
  ```typescript
  const used = await db.select({ id: bahan.id }).from(bahan)
    .where(and(eq(bahan.satuanId, id), isNull(bahan.deletedAt))).limit(1);
  if (used.length > 0) return { error: "Satuan tidak bisa dihapus — masih dipakai bahan. Nonaktifkan saja." };
  ```
