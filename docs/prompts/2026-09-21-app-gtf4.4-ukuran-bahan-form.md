## Task 3 — Dropdown pemilih bahan (JANGAN dilewati)

Ini bagian yang paling penting, dan paling mudah terlupa.

Nama bahan sudah dibersihkan, jadi sekarang ada **tiga** `Vision GMC No5` yang
namanya identik. Di dropdown, user tidak bisa membedakan resleting 30inch dari
32inch.

Ubah label dropdown jadi:
```tsx
`${b.kode} — ${b.nama}${b.ukuran ? " · " + b.ukuran : ""}`
```

Cari semua pemakainya:
```bash
grep -rn 'kode.*—.*nama\|kode} — ${' src/app --include="*.tsx" | grep -i bahan
```

Minimal ada di form Barang Masuk, Barang Keluar, dan BOM. Periksa sendiri,
jangan hanya tiga itu.
