## Task 4 — Tiga form pakai dropdown

| File | Field |
|---|---|
| `vendor/pengiriman/_components/PengirimanForm.tsx` | penerima |
| `vendor/penerimaan/_components/PenerimaanForm.tsx:179` | `pengirimVendor` |
| form serah terima bundel (cari pemakai `penerimaanBundelVendor`) | penerima |

Pola tiap field — **FK dan snapshot diisi bersamaan**:

```tsx
<ComboSelect
  label="Penerima (orang konveksi)"
  clearable
  options={kontakOptions.map((k) => ({
    label: k.jabatan ? `${k.nama} — ${k.jabatan}` : k.nama,
    value: k.id,
  }))}
  value={watch("kontakVendorId") || null}
  onChange={(v) => {
    const id = (v as string) ?? "";
    setValue("kontakVendorId", id);
    const k = kontakOptions.find((x) => x.id === id);
    setValue("penerima", k?.nama ?? ""); // snapshot — inilah inti fiturnya
  }}
/>
```

- Dropdown **disaring per vendor** yang dipilih di form itu
- Vendor belum punya kontak → form **tetap bisa disimpan**, teks diisi manual.
  Jangan blokir pengiriman barang gara-gara master belum diisi
- Kolom teks lama **tetap ada** dan tetap tersimpan — itu snapshot-nya
