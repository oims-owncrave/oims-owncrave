## Yang paling mudah salah

**1. Halaman master Bagian Produk belum ada — harus dibuat** (Task 2). Ikut pola
halaman Jenis Cacat (`src/app/(with-layout)/master/jenis-cacat/`). Urutkan daftar
pakai kolom `urutan` (10, 20, 30…), **BUKAN abjad** — supaya tampil mengikuti
urutan fisik jaket dari atas ke bawah.

**2. Kode auto-generate pakai `generateDocNumber`** (`src/lib/document-number.ts`),
jangan bikin generator baru. Kalau memakai `regexp_replace`, tulis `'\\D'` bukan
`'\D'` — postgres.js membuang backslash tunggal di tagged template. Sudah pernah
kena di 3 fungsi generate kode.

**3. ComboSelect wajib pakai filter ini**, kalau tidak transaksi lama yang
menunjuk master nonaktif akan tampil kosong — datanya ada tapi tak terbaca:
```tsx
options={master
  .filter((m) => m.isActive || m.id === nilaiTersimpan)
  .map((m) => ({ label: `${m.kode} — ${m.nama}`, value: m.id }))}
```
Field opsional tambahkan prop `clearable` (prop baru dari app-46vb).

**4. Guard halaman baru pakai pola ini** (app-qdqu, 21 Sep):
```tsx
import { bolehAkses } from "@/lib/auth";
import { AksesDitolak } from "@/components/ui/AksesDitolak";

if (!(await bolehAkses(["owner", "admin_produksi"]))) return <AksesDitolak />;
```
JANGAN `await requireRole([...])` di halaman — itu melempar dan membuat halaman
crash dengan overlay Runtime Error. `requireRole` tetap benar di dalam service.

**5. Entri nav baru** di `src/components/layouts/sidebar/data/index.ts`, grup
Master Data dekat "Jenis Cacat" (heading "Data QC"). Sidebar sekarang punya
filter role (app-qr6o) — entri **tanpa** `roles` berarti terlihat semua role, dan
itu BENAR untuk master ini karena master lain di grup yang sama juga belum punya
`requireRole`. Jangan menambah `roles` yang lebih ketat dari yang dienforce
service.

**6. Data lama sengaja NULL.** Dua baris uji di `retur_jahit_detail` dev
(`"Jahitan bahu lepas"`, `"Jahitan kerah bergelombang"`) dibiarkan `jenis_cacat_id`
NULL karena master `jenis_cacat` di dev kosong — tidak dipetakan ke tebakan.
Tampilan harus tahan nilai NULL (tampilkan `—`), bukan crash.

**7. JANGAN sentuh 4 tempat yang sudah memakai `jenis_cacat_id` dengan benar**
(`schema.ts` sekitar `:1643`, `:1754`, `:1807`). Itu sudah FK sejak awal dan
bukan bagian dari issue ini.
